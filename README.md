
# Darinel Arrieta | Asistencia Legal

Sitio web profesional para **Darinel Arrieta Asistencia Legal**, enfocado en presentar servicios de orientación jurídica preventiva, facilitar el contacto con potenciales clientes y ofrecer información jurídica de interés.

## Descripción

El proyecto busca transmitir confianza, claridad y profesionalismo mediante una interfaz moderna, adaptable a dispositivos móviles y con una identidad visual basada en azul oscuro, dorado y tonos neutros.

La propuesta destaca la importancia de comprender cada situación jurídica, identificar posibles riesgos y evaluar alternativas antes de tomar decisiones importantes.

## Funcionalidades

- Presentación profesional y sección «Sobre Darinel».
- Catálogo de servicios de orientación jurídica.
- Sección informativa con artículos de la Constitución Política de Colombia.
- Acceso directo para solicitar asesoría por WhatsApp.
- Diseño adaptable a computadores, tabletas y celulares.
- Componentes reutilizables y estilos organizados por sección.

## Servicios presentados

- Deudas y centrales de riesgo.
- Familia y sucesiones.
- Tránsito y movilidad.
- Pensiones y seguridad social.
- Contratos y asuntos civiles.
- Asesoría empresarial y administrativa.

La información del sitio es general y no sustituye el análisis individual de cada caso jurídico.

## Requisitos

- Node.js compatible con la versión de Angular del proyecto.
- npm.
- Git (opcional, para clonar el repositorio).

## Instalación y ejecución

Clona el repositorio:

```bash
git clone https://github.com/TU-USUARIO/darinel-arrieta-asistencia-legal.git
```

Entra en la carpeta del proyecto:

```bash
cd darinel-arrieta-asistencia-legal
```

Instala las dependencias:

```bash
npm install
```

Inicia el servidor de desarrollo:

```bash
npm start
```

Abre en el navegador la dirección que indique Angular, normalmente `http://localhost:4200/`.

## Compilación

Para generar la versión de producción:

```bash
npm run build
```

Los archivos compilados se generan en el directorio configurado por Angular.
